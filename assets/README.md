# PyASL Centralized Branding Assets

This directory contains application branding assets used across development runs, PyInstaller standalone bundles, taskbar icons, and Windows installers.

Files:
- `logo.png`: High-resolution application branding logo.
- `logo.ico`: Windows icon file for window titlebars and taskbar decoration.
- `icon.ico`: Main executable and installer icon.
- `splash.png`: Application startup splash screen image.
